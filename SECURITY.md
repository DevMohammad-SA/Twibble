# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Twibble, please report it privately.

Do **NOT** open a public GitHub issue.

Instead, report it via:

- GitHub Security Advisories (preferred)  
- Email: dev.mohammad@tuta.io

Please include:

- Description of the issue  
- Steps to reproduce  
- Potential impact  

---

## Supported Versions

Only the latest version on the `main` branch is supported with security updates.

---

## Responsible Disclosure

Please do not publicly disclose the vulnerability until it has been fixed.

Your help in improving Twibble’s security is appreciated.
